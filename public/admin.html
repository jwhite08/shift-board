Office locations & extensions

Each location can have several workstations. Every workstation has its own phone extension and a seat count — set Seats to 2+ for shared pods (e.g. a provider + their primary). Use the ▲ ▼ buttons to reorder — this changes the order locations appear on the main board.

Staff

Names shown in the "set my location" dropdown on the main board. Duplicate names are flagged automatically. Email and role are used for schedule notifications (coming soon) — both are optional for now.
